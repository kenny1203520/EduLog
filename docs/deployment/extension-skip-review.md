# EduLog 0.1.0：略過報告再確認與教材排序

套用資料庫 migration `1000132_extension_report_skip_decisions.sql`（前置版本為 1000131），部署相符 API，再載入 `EduLog-Teaching-Tools-0.1.0-skip-review-reconfirm.zip`。側載包只附 migration，不會自行執行 SQL。

成功重新讀取來源後，工作台會比對老師先前確認略過的報告。內容改變、對應關係改變或確認超過 30 天時，報告會回到待處理清單；老師可逐筆恢復核對，或多選後明確確認繼續略過。未重新確認前不會寫入。未提供跨裝置能力時，舊伺服器不會宣稱已記住略過選擇。

教材選項依有效 Lesson 序號數值排序；重複序號保留所有候選並按名稱與 ID 排列，缺少序號者置底。標籤使用 `Lesson N · 名稱`，教材 ID 和既有選取值維持不變。

更新前先保存原站表單草稿，再重新載入擴充套件及工作台。自動驗收使用去識別化資料；本次未在真實站點送出教學報告。Chrome／Edge 真實側載、實際跨裝置、鍵盤與 200% 縮放仍待驗收。
