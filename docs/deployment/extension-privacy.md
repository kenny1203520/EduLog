# EduLog Teaching Tools 隱私政策草稿

更新日期：2026-10-18。上架前須由發佈者確認、補上正式聯絡方式，發布為不需登入即可讀取的公開網頁。

EduLog Teaching Tools 協助使用者在支援的教學網站與自行指定的 EduLog 系統之間檢視、預覽及同步教學紀錄。

## 資料與用途

擴充功能讀取支援教學頁面的學生／報名識別資訊、課程、日期、出席、教學內容及使用者選取的內部紀錄，以提供頁面輔助、差異預覽、報告預填及同步，不會自動提交原站教學表單。

使用者明確啟動讀取、預覽、同步或預填時，所需內容會在來源網站、擴充功能及使用者指定的 EduLog 伺服器之間傳輸。伺服器依帳號權限處理學生、課程、報告、來源連結、同步及配對紀錄。

本機保存偏好、語言、欄位映射、隨機安裝 UUID、裝置名稱及粗略瀏覽器／OS 標籤。UUID 不是硬體識別碼。配對憑證保存於擴充功能的受信任儲存空間，不提供給來源網站內容腳本。

為了在頁面開啟時立即套用主題，支援網站的 localStorage 另存主題開關及各頁原版模式的快取。這份快取不含配對憑證、安裝 UUID 或教學內容，來源網站可以讀取或變更；實際偏好仍由擴充功能確認。

工作草稿與來源暫存資料保存在擴充功能 IndexedDB，依既有七天及完成／取消清理規則處理。已確認同步的伺服器紀錄不因取消本機工作或移除擴充功能而刪除。

診斷包含錯誤碼、階段、request ID、工作／批次識別碼、版本及大小等必要資訊。回報問題前移除學生個資，不附憑證或完整教學內容。

## 傳輸、第三方與使用者控制

正式 EduLog 要求 HTTPS；localhost HTTP 僅供開發。擴充功能沒有廣告、行銷追蹤或分析服務，不使用 Chrome storage sync 傳送偏好。資料不出售，不用於廣告、信用評分或無關用途。

來源教學網站與自架 EduLog 營運者依其政策管理資料；Chrome／Edge 與商店安裝更新適用其各自政策。

使用者可停用頁面輔助、拒絕站點權限、取消工作、在 EduLog 撤銷配對，或移除擴充功能清除本機資料。伺服器紀錄的查閱、修改、保留與刪除請聯絡該 EduLog 管理者。
