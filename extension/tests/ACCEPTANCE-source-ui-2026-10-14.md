# 原站介面與 RWD 修正（0.1.0）

## 本次範圍

以班級頁附件檢視共用介面，修正手機單堂報告卡片因內距及邊框造成的整頁溢位、學生名單固定 600px 空白、過小輔助文字及詳情點擊範圍。班級下拉限制視窗寬度，內容區使用 border-box；課次工具列允許依可用寬度換行。原生節點、表單、Turbo 及主題還原沿用現有機制。

整班摘要未開始時不顯示 0/0 進度。讀取拒絕後解除忙碌狀態，保留已取得結果，允許再次讀取；沿用繁中／英文的讀取失敗文字。

## 已驗證

- 完整擴充功能測試：319/319 通過。涵蓋原生操作、輸入保留、主題還原與 Turbo；新增摘要初始狀態、讀取失敗及重試回歸。
- 修正 browser-check.mjs 未等待 evaluateHandle 回應的驗收腳本錯誤。
- Chrome 合成瀏覽器：12 種支援頁面 × 360、390、768、1024、1200、1440、1920、720px，均通過現有版面與操作斷言；另有 4 種擴充功能彈出頁狀態。360px 單堂卡片溢位由此檢查重現並修復。
- 合成頁使用本機 native-bootstrap-dialog.css 樣本，不代表完整實站 CSS 驗收；所有請求以本機樣本回覆，沒有提交教學資料。
- 版本維持 0.1.0，重建既有側載包。
