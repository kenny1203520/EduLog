## 實站待驗證

重新載入擴充套件後，先儲存正在編輯的內容，再重新整理網站頁面。

- Chrome 使用新版腳本逐頁確認；Edge 實站側載及原生 200% 縮放仍需人工檢查。
- 檢查捲動後開窗、視窗重開、備註 → 總評 → 報告切換、導覽／下拉／提示浮層及焦點回到原生入口。
- 學生帳號設定入口本次實站未呈現可靠視窗內容，保留原站行為，未列為已改善或已通過。
- 簽到確認樣本尚未取得；簽到檢查曾被自動審核攔下，以避免建立出勤紀錄，未執行簽到。
- 報告人工送出成功畫面仍未驗證；資料匯入、預填及推送回寫不在此階段。

- 15 個啟動／生命週期測試在主要 DOM 建立前執行 bootstrap，涵蓋立即與延遲回應、停用、拒絕、300ms 逾時、DOM 尚未準備、遲到回應、本頁手動選擇、未知頁、權限錯誤、快取清理、render 失敗、取消與連續導覽，以及 frame／表格更新保留原生輸入與工具列。快取重建亦驗證可靠欄位 ID 的焦點與游標還原。
- Chrome／Edge 各 390、1440px，7 種啟動情境，共 28 組逐影格檢查及 WebM 錄影。已啟用的可見影格均具有改善模式與 DOM 增強；逾時／失敗的原站不被遲到回應切換。另涵蓋刷新、三次快取／渲染交易、未知頁進入支援頁、frame 更新及未送出內容。

- 既有 120 組頁面幾何回歸及 8 組 popup 檢查亦通過。原生 200% 縮放仍屬待驗證項目。
- 錄影／結果：`extension-startup-v010`（交付目錄），包含 `startup-results.json`；版面截圖另存 `extension-startup-layout-v010`。

# 清晰主題、整合規劃與連線管理（2026-10-01）

- 版本維持 **0.1.0**。主題名稱為 **EduLog 清晰主題**，操作為「套用清晰主題／使用原站主題」。
- Popup 與網站整合面板提供教學資料匯入、報告預填的可展開流程卡片；皆標示尚未開放，沒有執行資料操作。
- 每個瀏覽器設定檔使用隨機安裝 UUID；可命名、重新命名連線。相同使用者／擴充套件／已知安裝重新配對時，原授權被原子取代。
- 不依產品 ID 合併未知舊授權。舊紀錄顯示未辨識提示及獨立連線編號；目前瀏覽器重新驗證時，只補上其持有憑證的安裝資料。
- 配對中清單每 2 秒更新；一般每 10 秒更新，回到分頁立即更新，隱藏時暫停。背景更新保留清單、命名輸入與焦點；撤銷提供具名確認。

自動驗證：

- 擴充套件 **76** 個單元測試：既有原站內容保留、啟動生命週期及連線狀態，新增安裝識別、舊憑證補資料、命名配對與重複送出防護及舊驗證不覆蓋新配對。
- 網站連線元件 **5** 個測試：claim 後自動列入、相同產品 ID 的舊紀錄辨識、背景更新保留命名、撤銷確認／取消、離線保留資料及隱藏暫停。
