# 歷史核對、混合保存與原子課次更新

版本：`0.1.0`

## 已執行

- Extension：全套回歸通過；含歷史核對、600 份工作單筆確認、混合文字編輯、空白清除確認及同頁即時更新。
- API：`extensionWorkspaceRouter.test.ts` 24 項通過；核對 metadata 僅接受允許欄位，拒絕本機 preview 指紋及非歷史資料列。
- TypeScript：server typecheck 通過。
- PGlite：實際執行 migration `1000134_atomic_history_reconciliation.sql`；驗證預覽的目標版本、歷史與課次報告保存一致，以及課次更新失敗時歷史與課次皆回滾。

## 行為驗證

- 舊映射記憶失效不再阻擋以目前有效選擇重新核對；身份、課程、權限及目標版本仍由目前資料驗證。
- 「先存歷史」使用同一套必要核對，未通過時不產生寫入資料。
- 文字欄位可選來源、EduLog、逐行混合或不同步。共同行保留一次，來源新增行預設不選，EduLog 差異行預設保留；手動編輯不會被勾選操作覆蓋。
- 混合結果為空時，需先勾選清除確認，再執行「核對並保存決定」。保存歷史與課次報告只發生於最後同步。
- 有課次時，歷史內容與課次報告在同一資料庫交易使用相同欄位結果；原始來源證據另行保留。已綁定報告只可更新原連結目標。
