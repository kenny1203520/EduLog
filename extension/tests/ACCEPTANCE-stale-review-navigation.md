# 待確認清單與核對跳轉驗收

## 本次修正

- 待確認清單將欄位問題依穩定報告識別分組；32 個欄位問題會呈現為 18 份報告。
- 「開始核對」與「前往核對」先切換至正確工作階段及核對分頁，再選取報告、展開欄位並移動焦點。搜尋或篩選隱藏的報告仍可定位。
- 報告核對區提供學生、課程、日期、比較對象及剩餘欄位數；欄位選單提供保留 EduLog、採用來源、文字混合及不同步。缺少舊選擇時明確標示舊草稿未保存原選擇。
- 返回摘要時重畫待確認數，還原先前展開的差異、報告焦點與頁面位置。學生／報名問題會進入既有身份核對畫面。
- 同步按鈕共用資格判定；預覽過期、尚有待確認、差異已變更或草稿保存未完成時均保持停用。摘要只顯示一份預覽失效提示。
