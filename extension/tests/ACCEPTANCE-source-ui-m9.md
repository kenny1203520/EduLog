# 原站改版 M9：多班級、多異常、多分校（0.1.0）

## 本次範圍

- **班級名單消失（修正）**：實站的色塊圖例和名單表格在同一個 `.row`，M8 把整個 `.row` 隱藏，連搜尋框、篩選籤、卡片和表格都看不到。現在只隱藏 `.color-labels`；fixture 改成實站結構，測試會抓到這個回歸。
- **導覽列**：
  - 班級分在不同分校時，副標自動加上分校（例如「樹林 非凡文理 · 201教室（菁英）」）；全部同分校時維持「201教室（菁英）」。
  - 超過 6 個班時依星期分組，今天的組放最上面並在標題寫「（今天）」；電腦版導覽列可獨立捲動。
  - 待處理數字改由其他畫面讀到資料後通知導覽列更新，不另外讀取。
- **總覽「本週待辦」**：
  - 「待填報告」與「本週點名與出席」（原「出席異常」，合併待點名與缺席）都依班級分組：班級只寫一次（星期時間、地點、計數、一個「前往」連結），組內只列姓名與徽章；每組超過 5 位時收合為「顯示其餘 N 位」。待填報告保留每位學生的「去填寫」。
  - 只有已開始的課次（課堂記錄表本週日期＋班名時段的開始時間已過）才算待點名；還沒上課的班顯示「N 個班本週還沒上課，開始上課後才會列入」，導覽列數字也記為 0。
  - 最多讀 20 個班，同時 3 個請求，今天的班優先、其次是本週已上過的班；超過時顯示「只檢查了 20 / N 個班」。
- **課堂記錄卡片**：本堂還沒開始時，比照下週課次，不列待點名與資料未齊，並說明原因。
- **正常學生收合**：「全部」篩選下，若有其他學生需要處理，沒有任何事項的學生收成一列「其他 N 位狀態正常」（名單為「其他 N 位沒有特別狀態」）。
- **精簡列**：1024px 以上，課堂記錄與名單各有「精簡列」切換，只保留姓名、狀態與操作；選擇分別記在 `edulogUiPreferences` 的 `density`（只在精簡時儲存，不影響其他偏好）。
- **還原修正**：篩選掉的卡片改為留在清單中隱藏，不再移出 DOM；否則卡片裡移入的原站元件（筆電借用 frame、上次教學面板）在還原時會被當成已刪除而遺失。
