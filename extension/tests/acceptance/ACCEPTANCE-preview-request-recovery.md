# 驗收紀錄：預覽請求與續傳修復

版本維持 **0.1.0**。本次沿用既有匯入 API、工作草稿與批次檢查點，不新增端點或 migration。

## 已驗證

- 預覽與同步請求只包含 API 契約欄位 `key`、`rows` 及可選的 `dependencies`；本機 `previewFingerprint` 不會送出。
- 伺服器仍以嚴格 schema 拒絕未識別欄位，並在呼叫匯入 RPC 前拒絕該請求。
- 預覽取得指紋後，續查及同步保留原批次 key、資料和相依指紋；草稿中的本機指紋不被轉換流程修改。
- 續傳核對失敗時，舊摘要立即失效、同步按鈕維持停用，未知寫入狀態與原檢查點保留；核對成功後才恢復確認操作。
- 擴充功能完整測試 **254 項通過**；匯入預覽定向測試 **17 項通過**；伺服器路由契約測試 **23 項通過**。
- 側載封裝對套件內 JavaScript 執行語法檢查，封裝完成並保留版本 **0.1.0**。
