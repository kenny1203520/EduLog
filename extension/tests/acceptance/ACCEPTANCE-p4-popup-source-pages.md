# P4：Popup 與原站頁重繪（2026-10-18）

依 `docs/design/MASTER.md` 與已核准原型 `docs/design/prototype/index.html`。

## 本次範圍

- **Popup（360px）**：頂部連線狀態標籤（已連線／未連線／等待核准／連線異常）＋齒輪。未連線只有一顆「連接 EduLog」（沿用原配對流程，連線名稱收在「此瀏覽器的連線名稱」展開）。已連線時依目前分頁（`chrome.tabs.query`，頁面判斷沿用 `orange-apple-lexicon.js` 的 `paths`）只顯示一個主操作：班級頁「同步本班」、報告編輯頁「預填本報告」、其他頁「開啟工作台」；班級頁另有文字連結「開啟工作台」。底部「工作紀錄（N）」。主題、語言、伺服器、最近驗證、整合設定、變更伺服器收在齒輪後的設定頁。伺服器未提供對應能力時主按鈕停用並說明。
- **班級頁 `/courses/dt/<id>`**：每位學生一列：姓名＋標籤、課程 · 本堂 · 課次 · 最後上課、四項狀態（出席／完成狀況／內部紀錄／學習表現，圓點＋文字）、一個主操作（點名與紀錄／填寫紀錄；已齊為次要「查看紀錄」）。
  - 過去、本週（含尚未開課）、下週**一律顯示四項狀態與填寫入口**；移除 `upcoming = 下週 || notStarted` 的隱藏與「本堂還沒開始上課…」提示。本堂未開始改為資訊提示「現在就可以先點名、填寫紀錄」。
  - 下週未填項目為灰色（neutral），不列入待處理、沒有琥珀色條；下週預設篩選「全部」，過去與本週有待處理時預設「待處理」。每次切換課次回到該課次的預設篩選。
  - 原站沒有編輯連結：四項狀態顯示「原站未開放」、名字旁標籤「原站未開放」、操作欄「—」；缺席與暫停等資訊照常顯示。
  - 狀態只用左側 3px 色條與小圓點，不再整格填黃／紅。常駐篩選：待處理／未點名／資料未齊／全部；需關注、請假／缺席、已完成、原站未開放、非本堂收在「更多」，選中時「更多」顯示該篩選名稱。
  - 「未點名」狀態在有快速點名區塊時可點，跳到該生的點名格。
- **未填頁 `/admissions/unfilled_report`、月未填頁 `/admissions/month_unfilled_report`**：共用同一套列。依「學習紀錄節次」分組（標題附課程），列中有「請儘速填寫／逾期」的放到最上方「逾期未填」組並標紅；每列一顆「填寫」（點原站連結）；學習紀錄節次 ≠ 目前節次時加「節次不一致」標籤；電話按「顯示電話」才出現（`tel:` 連結）。原生表格保留但隱藏，本頁搜尋同時過濾原生列與新列；分組可收合。
- **報告 modal**：`editor-prefill.css` 改用 tokens（標題字級、外框圓角與陰影、分頁切換用淡藍選取、未連線的「連接 EduLog 以啟用報告助手」為小型次按鈕）。P0 的連線閘門行為（`editor-prefill.js`）未變。
- Icon 全部改為 Lucide 內嵌 SVG，無 emoji。
