# 原站改版 M7：課堂記錄編輯器（0.1.0）

## 本次範圍

新模組 `sites/orange-apple/orange-apple-report-editor.js`，由既有 `enhanceDialog`（欄位分區）呼叫：

- 頂部「四項狀態」列（出席｜完成狀況｜內部紀錄｜學習表現），隨欄位即時更新，與課堂紀錄卡片的狀態列一致；完成狀況區分「完整完成／章節未填／尚未完成／未填」。
- 不出席：課程與專案進度、課堂評量、內部紀錄與學習表現標為不適用而隱藏，只留不出席原因與聯絡欄，並顯示說明；改回出席即恢復。
- 評分：既有的評分下拉保留，星星放大，每項加「清除評分」（取消原生 radio 並觸發原生事件）。
- 片語庫：讀原生 `#report-options` 的類別（學習表現前言、課程理解…）與等級（優良／普通／不佳），類別分頁（左右鍵切換）＋等級分組，點一句即插入學習表現游標處並觸發原生 `input`／`change`（原站確認勾選規則照常運作）；「今天的進度第＿課」自動帶入所選學習課程課號，「上次的第＿課」保留給老師填。原生「+」與片語面板隱藏（可還原）。≥1024px 片語庫與學習表現並排。
- 「課堂紀錄填寫異常(教學部使用)」移入預設關閉的「教學部使用」區塊。
- 送出區上方顯示未完成項目（不阻擋送出，點擊跳到欄位）；全部完成時顯示「必要項目都已填寫」。送出仍是原站按鈕。
- 偏離計畫：片語庫放在學習表現旁（同一區塊內），不另做右側分頁欄，以免與既有 EduLog 預填助手的雙欄版面衝突。
