# EduLog 0.1.0：編輯區錯誤與工作恢復修復

## 修復結果

- `editorDataSignature` 已成為工作台實例狀態，選取報告、切換工作及移除報告時會更新或清除。
- 欄位對應只有在課程識別有效且與選擇記憶相符時才會沿用。課程或欄位選項缺失時不再誤判為有效對應，也不會讀取不存在的 `fields`。
- 工作紀錄的「繼續核對」會保存目前草稿、恢復來源與對應介面，並用既有批次鍵重新建立預覽。此流程不會直接寫入教學資料。
- 預覽失敗會使舊摘要失效、停用同步並提供重試狀態；恢復期間遇到無效來源或缺少檢查點時會顯示可處理的錯誤。
