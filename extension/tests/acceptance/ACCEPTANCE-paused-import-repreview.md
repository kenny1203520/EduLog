# EduLog 0.1.0：暫停工作重新核對

## 已驗證

- PGlite 套用 migration 1000138 後，暫停中的匯入工作可重複產生預覽，預覽後仍維持暫停。
- 暫停中的工作仍拒絕直接寫入；只有明確切換至寫入狀態後才可套用批次。
- 已取消與已完成工作不能重新預覽。
- 擴充功能恢復流程先讀取伺服器工作狀態與批次檢查點，再使用原工作與原批次鍵核對；不因恢復而建立工作或套用教學資料。
- 伺服器回報取消或完成時不呼叫預覽。舊伺服器拒絕暫停預覽時只補查一次狀態，提示更新伺服器，且不自動重建或重送。
- 所有批次已確認保存時，介面等待老師明確確認本輪完成，不自動執行課次收尾。

## 自動化驗收

- `extension/tests/workspace-preview.test.mjs`：恢復狀態、檢查點、取消／完成、舊伺服器拒絕及明確完成操作。
- `supabase/tests/web_extension_workspace.mjs`：真實 migration 契約及 PGlite 交易測試。
- 側載封裝會將 migration 1000138 與本驗收紀錄納入封裝，並對封裝中的 JavaScript 執行語法檢查。

## 待驗收

- Chrome 與 Edge 實際側載通訊、跨裝置狀態變動與鍵盤／焦點／捲動保留尚未在真實瀏覽器驗證。
- 實站僅供唯讀檢視；尚未對實際教學資料執行同步。
