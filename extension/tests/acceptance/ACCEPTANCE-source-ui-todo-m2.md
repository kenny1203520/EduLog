# 原站改版 M2：總覽「本週待辦」任務視圖（0.1.0）

## 本次範圍

教師總覽 `/` 最上方新增擴充自繪的「本週待辦」，原站總覽內容（課表基準日期、我的班級、原站課程表）保留在下方。可在 EduLog 面板關閉「本頁套用 EduLog」整頁回原站。

- 資料：同源唯讀讀取 `/admissions/month_unfilled_report`、`/admissions/unfilled_report`、`/calendar`、`/my/hour` 與側欄班級的 `/courses/dt/:id/lesson_reports`（最多 8 班、同時 2 個請求）。路徑白名單、`credentials: same-origin`、`redirect: error`，不送出任何表單。分頁內記憶 5 分鐘，「重新整理」強制重讀，標示「更新於 hh:mm」。
- 區塊（各自載入、各自失敗與重試，不互相阻塞）：
  1. 待填報告：月未填寫（上月份）標「逾期未填」置頂，補填列表標「待補填」；重複項目合併。每列「去填寫」連到原站。附「設定 EduLog 配對」引導，改版本身不需配對。
  2. 本週課表：行事曆中屬於側欄班級的課次，今天標「今天」。
  3. 出席異常：本週欄「缺席／未出席」與「待確認出席」，缺席置頂；非本班學生略過。
  4. 本月時數：鐘點紀錄筆數（鐘點可解析為數字時附合計）。
- 異常優先：只有需處理的項目使用徽章，徽章同時有圖示（SVG）與文字；空狀態以「本週報告都填完了」等正向訊息呈現。
- 樣式：手機優先單欄，1024px 以上待填報告在左、其他區塊在右。44px 觸控、14/16px 文字、skeleton 載入並遵守 `prefers-reduced-motion`。新增 tokens：`--edulog-status-danger-soft/-text`。
- 詞彙表新增讀取來源、未填寫欄位、日期與缺席用語。
