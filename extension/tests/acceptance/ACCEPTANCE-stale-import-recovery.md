# EduLog 0.1.0：同步失效恢復與剩餘工作

## 已實作

- `PREVIEW_STALE` 會停止本輪後續寫入、停用舊摘要並保留失敗批次鍵、已完成檢查點與原工作識別。失效狀態明確顯示目前批次未提交，成功批次仍保留。
- 重新核對沿用原批次及依賴識別，不會自動提交。先前的覆寫決定要求重新確認；確認後仍須重新產生摘要，才能進入同步操作。
- 後續提交輪次只組裝尚未保存的來源報告，並以唯讀匯入檢查點顯示歷輪結果。伺服器以帳號範圍關聯工作與匯入工作，並使用 revision 核對 metadata 更新。
- `PREVIEW_STALE` 僅在可以安全識別原因時回傳白名單診斷；舊資料庫或無法安全定位時使用中性錯誤，不回傳報告正文或無權讀取的資料。
- 摘要分開呈現本機草稿和伺服器同步結果。待處理報告不進入下一輪 payload；使用者需在待處理清單完成核對後另行產生新摘要。

## 自動驗收

- 擴充功能全套測試：**275 項通過**，包含 stale 後停止寫入、保留已成功批次與失效鍵、後續輪次排除已完成報告、伺服器輪次與本機檢查點合併、失效狀態保持可見，以及繁中／英文切換與理由翻譯。
- API 全套測試：**235 項通過**，包含工作輪次欄位白名單與 stale 診斷回應限制。
- PGlite 工作區回歸通過：執行 `1000136`，驗證多輪關聯、revision、預覽指紋失效與目標版本變動診斷。
- 伺服器 TypeScript 型別檢查通過。
- Chrome／Edge 合成工作台測試通過：無來源分頁啟動、草稿失敗後明確重試、IndexedDB 檢查及 360／390／768／1024／1200／1440／1920px 工作台檢視。測試使用 mock API，不會連線或寫入實站。
- 側載封裝會檢查 staging 內 JavaScript 語法、入口檔及本機依賴，並包含 migration `1000136` 與本驗收文件。

## 待驗收

- 尚未在使用者的 Chrome／Edge 設定檔側載此版，因此真實背景服務重啟、跨裝置帳號及 74 MB 草稿的端到端表現待驗收。
- 本次未對來源網站提交任何教學紀錄；實站教學資料寫入流程待驗收。
- 合成測試未涵蓋 480px 短視窗、原生 200% 縮放及實際側載背景服務重啟；這些項目仍待驗收。

## 部署

- 新增資料庫 migration：`1000136_import_preview_diagnostics_and_work_rounds.sql`。部署前應先備份資料庫，依版本順序套用 migration；舊伺服器不提供原因診斷或跨裝置輪次關聯時，介面會保留安全重查能力並提示跨裝置限制。
- 側載包：`extension/dist/EduLog-Teaching-Tools-0.1.0-stale-import-recovery.zip`。
- 版本維持 **0.1.0**；未新增 API 端點，仍使用既有工作紀錄與匯入查詢／提交端點。
