# 原站改版 M8：班級名單卡片（0.1.0）

## 本次範圍

新模組 `sites/orange-apple/orange-apple-roster.js`，由 adapter 既有的名單區（`#students-table`）呼叫：

- 每筆報名一張卡片：姓名（有教學備註時加圖示）、年級與課程、上課期間（尚未開課改顯示「預計 YYYY/MM/DD 開課」）、「剩餘 x / y 堂」與進度條、補課數。≥1024px 每張卡片一橫列且欄位對齊。
- 徽章（顏色＋圖示＋文字）：剩餘 0 堂（紅）、剩餘 1–2 堂（琥珀）、尚未開課・預計日期、本週試聽、已試聽、調課、進度較慢、同名 N 筆報名。
- 篩選籤：全部｜剩餘少｜尚未開課｜特殊狀態（含同名多筆），預設全部；排序為剩餘 0 堂 → 剩餘 1–2 堂 → 原站順序。與既有「目前名單篩選」搜尋同時作用，計數顯示「顯示 x / y 位學生」。
- 原站色塊圖例隱藏（由文字徽章取代）；原生表格保留在 DOM 中隱藏，關閉「本頁套用 EduLog」可見。
- 所有操作仍走原站控制項：卡片「選取」與工具列「全選名單」點擊原生勾選框（Stimulus `checkbox` 控制器照常收到 change）；「更多」內的「教學備註」點原生連結；原生筆電借用下拉（`turbo-frame#laptop_*`）移入「更多」，還原時放回原位；「完整紀錄」取同頁課堂記錄表中同一 admission 的連結。
- 名單卡片使用獨立的 class／`data-roster-chip`，不與課堂記錄卡片互相干擾。

## 已驗證

## 待驗收（實站側載）

- 列狀態標記：試聽／已試聽／調課是否為列 class `audition`／`auditioned`／`temp-transfer`，進度較慢是否為列底色 `#F39C12`（目前依圖例推測）。
- 每列勾選框：實站樣本的列首欄是空的，假設為 `data-checkbox-target="checkbox"` 的原生 checkbox；請確認何時出現、全選後卡片勾選是否同步。
- 筆電借用下拉移入「更多」後，原站 Turbo 更新 frame 時的顯示。
- 同名判斷只依姓名，可能把不同學生視為同名多筆（徽章文字為「同名」而非「同學生」）。
