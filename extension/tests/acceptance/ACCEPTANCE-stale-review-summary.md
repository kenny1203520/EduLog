# EduLog 0.1.0：可辨識的同步摘要與重新核對

## 交付內容

- 預覽失效的歷史報告按學生、課程、報名、日期與同步目的地呈現；來源值、EduLog 現值及原決定收在欄位詳情，技術識別收在「診斷與來源證據」。
- 「前往核對」會清除搜尋／篩選限制並定位原報告及問題欄位。使用原核對區保存逐欄決定；每個失效欄位都必須重新選擇，摘要操作不直接改寫同步 payload。
- 保存後仍可返回摘要；預覽成功前同步維持停用。更新時沿用原批次與課次核對鍵，已提交批次不可改寫。
- 未新增 API、migration 或草稿格式；版本維持 0.1.0。

## 自動驗收

- 歷史同步與工作台測試覆蓋失效欄位重新確認、隱藏報告定位、篩選恢復、保存失敗保留選擇，以及已確認報告仍可返回摘要。
- 預覽測試覆蓋整理結果回寫原未提交批次、批次鍵／課次核對鍵保留，及已提交批次不可變更。
- 擴充功能完整測試：**286 項通過**。原始 ES 模組 syntax test 通過。
- Chrome／Edge 瀏覽器合成檢查未能啟動：執行環境拒絕瀏覽器連線本機測試伺服器（`ERR_NETWORK_ACCESS_DENIED`），因此版面互動保留待驗收。

## 待驗收

- 真實 Chrome／Edge 側載安裝、鍵盤完整操作、原生 200% 縮放與大型實際工作仍待實測。
- 未重放使用者的實際伺服器工作；本次變更沒有提交任何教學資料。實站操作僅讀取。
