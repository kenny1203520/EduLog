# 驗收紀錄：略過報告再確認與教材排序

版本維持 **0.1.0**。本功能新增 migration `1000132_extension_report_skip_decisions.sql` 與受限的略過決定 API；部署前須先完成 1000131。

## 已驗證

- Lesson 1、2、10 依數值排序；相同序號按名稱及 ID 穩定排序；缺序號置底。歷史教材選項使用相同排序器，保留教材 ID。
- 指紋區分欄位缺漏、空字串、零、`false` 及半星；擷取時間與控制順序不參與指紋。內部紀錄是否可讀的切換不會單獨造成整份報告變更；可讀時仍逐欄偵測內部紀錄變更。
- PGlite 執行 1000132：同帳號未變內容沿用、欄位變動重新確認、內部紀錄讀取範圍變化、30 天期限、revision 衝突、清除及帳號／EduLog 實例隔離通過。
- 工作台提供逐筆「恢復核對／繼續略過」及選取多筆後一次確認。API 每批最多 50 筆；確認後再保存草稿，決定未完成保存時保留選取。
- 已執行的擴充功能定向測試與 PGlite 套件通過。API 路由測試受限於目前執行環境禁止本機測試 TCP listener（`EACCES 127.0.0.1`）；純 schema 檢查通過，API TypeScript typecheck 通過。

## 尚待實站驗收

- Chrome／Edge 真實側載、不同裝置同步、30 天自然時間邊界、鍵盤操作、既定響應寬度、短視窗及 200% 縮放。
- 本輪只使用隔離測試資料，未提交任何來源教學報告。
