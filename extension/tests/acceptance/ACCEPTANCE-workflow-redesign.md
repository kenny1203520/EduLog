# EduLog 0.1.0 擴充功能操作流程重構驗收

日期：2026-10-08（Asia/Taipei）。本輪沒有資料庫變更、migration 或新 API；後續 migration 從 **1000130** 起，不使用 1000128／1000129。

## 交付與操作

- 原站維持點名、教學表單與人工送出；完整歷史、例外、同步摘要在工作台。
- Popup 首屏顯示當頁操作與工作入口，配對／診斷／主題／語言在次要設定。工具列按實際高度預留空間。
- 共用淺色藍色樣式與 `zh-TW`／`en` 語言偏好；新操作與狀態使用鍵值，既有自有文字使用受限相容目錄逐步轉換。來源內容及診斷保留原文。
- 工作階段依讀取、未解決問題、預覽與實際提交檢查點判定；進入過某階段不代表已完成。返回功能保留階段與原控制。
- 身份／課程與報告例外分頁，共用同步設定集中收合；目前報告不重複顯示整個身份表。
- 1200px 起來源左、EduLog 右，逐段 diff 顯示新增與刪除；較窄逐欄上下對照。處理選擇與同步後內容一起顯示。非空覆寫仍需確認。
- 結果先列實際歷史保存、課次綁定、保留、略過、失敗與待處理；工作紀錄只依相同伺服器 job ID 合併，保留來源、獨立錯誤及重試入口。
- 工作台最大 1600px、助手對話框最大 1440px。桌面每個主要面板只有一個捲動區；手機清單／編輯切換及頁面捲動。44px 操作、16px 正文、14px 輔助文字，安全區與可見焦點保留。

### 本輪兩項重現問題

1. 歷史核對後捲動改變：保留已解決問題列的高度與穩定識別，不移除當前報告；保存實際清單 `aside` 與編輯面板的位置。回歸驗證實際 `scrollTop`、頁面捲動、焦點與游標。
2. 關閉按鈕命中失敗：舊合成样本未提供原生 `.modal { display:none }`，多個未啟用浮窗重疊。新增可還原的離線 Bootstrap 幾何基線，分離主題與助手結構樣式；檢查可見關閉控制的 `elementFromPoint`。目前只是離線基線，正式站完整 CSS 與其他擴充套件的命中情境仍待側載驗收。

### 指引檢查

依 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 檢查本輪自有控制：標籤、鍵盤、可見焦點、`aria-live`、原文保護、長內容、段落差異、語意空值、捲動、安全區與無遠端字型。修正主要同步按鈕／步驟漏譯、查詢結束仍顯示載入、空來源路徑、原生浮窗的 scroll containment。
