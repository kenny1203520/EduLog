# 原站改版 M4：課堂紀錄單堂卡片與篩選籤（0.1.0）

## 本次範圍

依 2026-10-15 討論定案，重構班級頁「課堂記錄」分頁與課次報告頁：

- 單堂模式：每位學生一張擴充自繪卡片（≥1024px 為一橫列：姓名｜進度｜徽章｜操作；手機堆疊）。原生表格留在 DOM 但隱藏；三週比較維持原生表格。
- 控制列整併為一列：課次分段按鈕、單堂／三週切換、搜尋、篩選籤（待處理｜缺席｜未點名｜紀錄未填｜全部｜非本堂，含數量），「載入此課次全部摘要」收進「更多」。篩選籤取代舊的統計文字、學生篩選下拉、非本堂摺疊與 M3「本堂待處理」面板（已移除）。老師未自選時，有待處理預設「待處理」，否則「全部」並顯示完成訊息。篩選籤也套用到三週比較的原生列。（P4 已改為常駐 待處理／未點名／資料未齊／全部，其餘收進「更多」，見 ACCEPTANCE-p4-popup-source-pages.md。）
- 原站「請先點名…」提示列與「顯示本週上課／顯示全部」隱藏（本頁看原版仍可見）。
- 卡片正面：姓名（有教學備註時顯示圖示）、課程・本堂進度・最後上課階段、已啟用教材、狀態徽章、依狀態切換的主要操作：未點名「點名與紀錄」、已出席未填「填寫紀錄」、其他「查看紀錄」（次要樣式）。「啟用 L」僅在原站按鈕可用時出現，未點名時顯示「啟用需先點名」。
- 「更多」：完整紀錄、上次教學（內容移到卡片下方顯示）、教學備註、學生總評、學習帳號設定、專案檢查、出席統計。
- 排序：紅（缺席、課程到期）→ 琥珀（未點名、紀錄未填、剩餘 ≤2 堂）→ 正常 → 暫停（灰色徽章顯示原站狀態）→ 非本堂；同級維持原站順序。
- 所有會改變原站資料的操作都觸發原站原生連結／按鈕；擴充不自行送出。
- 修正：擴充 SVG 圖示未標記 `data-edulog-owned`，還原時會被當成原生內容留在頁面（M2 待辦亦受影響）。
