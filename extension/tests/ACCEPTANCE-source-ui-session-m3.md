# 原站改版 M3：圖示狀態讀取與「本堂待處理」（0.1.0）

## 實站發現

以真實班級頁 `/courses/dt/:id` 結構比對後確認：課次格的出席與課堂紀錄狀態是 Font Awesome 圖示加上外層 `span` 的 `text-success／text-danger／text-secondary`，不是文字。先前只比對「出席／缺席」文字，因此每格都顯示「原站未提供明確出席結果」，M2 的出席異常也讀不到。

圖示意義（教師確認）：人像 綠＝出席、紅＝缺席、灰＝未點名；筆 綠＝紀錄已填、灰＝未填；「課堂記錄」按鈕綠色只代表已點名／紀錄已建立。問號與對話圖示意義不同，暫不解讀。

## 本次範圍

- `orange-apple-model.js` 新增 `readSessionCell(cell, { upcoming })`：文字狀態加上圖示狀態（`attendanceMark`、`recordMark`、`recordCreated`、`recordPath`）。下週課次不列為待處理。
- 報告頁既有統計（已確認出席、已填紀錄、狀態待確認）、學生篩選、每格「出席狀態／課堂紀錄」摘要與 M2 出席異常改用圖示狀態。
- 新增 `orange-apple-session-panel.js`：在 `#reports` 上方（班級頁「課堂記錄」分頁與課次報告頁）顯示「本堂待處理」，依所選課次只列需處理的學生：缺席、課程已到期（紅）；尚未點名、已出席但紀錄未填、剩餘 ≤2 堂（琥珀）。其餘以一行摘要帶過，並提示非本堂學生人數。「課堂記錄」按鈕觸發原生連結，維持原站彈窗、Turbo 與日期情境；「完整紀錄」連到學生頁。切換課次即時重算。
- 剩餘堂數取自同頁班級名單（以 `data-admission-id` 對應，避免同名學生混淆）。
- 新增去識別實站結構樣本 `tests/fixtures/real-class.html`（名稱、編號、連結皆為佔位；保留 `<i class="fa …">` 圖示、`<br>` 週標題、名單與課次表結構）。
