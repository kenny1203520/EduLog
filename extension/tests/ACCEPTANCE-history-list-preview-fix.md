# 2026-10-10：歷史清單錯位與同步摘要修復

## 修正內容

- 一般歷史報告使用完整單欄寬度；只有可批次選取的報告保留獨立選取欄，操作範圍至少 44px。報告名稱可正常換行。
- 清單及編輯面板恢復時限制舊草稿捲動位置，避免錯誤的大數值把使用者帶離可見內容。
- 摘要只組裝已驗證的 `history` 與 `bind` 資料。尚未填寫、其他報名、系統排除、略過及已綁定列不建立報告 payload；未知分類及缺少必要關係會成為可見待處理問題。
- 新摘要開始時先作廢舊摘要並停用同步；只有資料驗證及預覽成功後才更新結果。續傳批次也會先驗證歷史報告必要欄位。
- 新增繁中／英文分類與參照錯誤訊息。

## 驗收結果

- 擴充功能 Node／JSDOM 全套：**243 項通過**。
- 歷史摘要整合測試走實際分類與資料組裝函式，確認排除列不進入寫入 payload、正常歷史仍能產生摘要，未知分類保留為待處理問題；不完整續傳批次在 API 呼叫前遭拒。
- Chrome 與 Edge 合成瀏覽器檢查：**16 種配置通過**（360、390、768、1024、1200、1440、1920px，另含 480px 短視窗）。檢查一般列及可選列寬度、44px 選取區、搜尋入口和末筆可達性。
- JavaScript 入口語法檢查及側載包內 JavaScript 檢查：封裝流程執行並通過。
